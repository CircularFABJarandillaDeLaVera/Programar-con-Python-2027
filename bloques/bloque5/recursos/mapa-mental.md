# Mapa mental - Bloque 5

## Flujo

DATOS -> PROCESAR -> ANALIZAR -> OBTENER INFORMACION -> AUTOMATIZAR -> RESULTADOS

## Ramas

- NumPy: arrays, np.nan y operaciones vectorizadas.
