# Practica 05 - Parsing e informe conceptual

## BeautifulSoup

Uso conceptual en este bloque: sirve para razonar sobre HTML estatico cuando no hace falta controlar un navegador.

## ReportLab

Uso conceptual en este bloque: disenar la estructura del informe antes de escribir APIs no trazadas.

## Tarea

Disena un informe de mercado con estas secciones:

1. Resumen
2. Tabla de ofertas
3. Precio medio
4. Alertas de stock
5. Conclusion

## Mini-reto

Indica que datos ocuparian una tabla y que textos deberian ir como parrafos para no desbordar el documento.
