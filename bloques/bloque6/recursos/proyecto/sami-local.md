# Proyecto B6 - SAMI-Local

## Evolucion

SAMI-Lite -> SAMI-OOP -> SAMI-Applied -> SAMI-Local

## Objetivo

Profesionalizar el entorno local de trabajo sin anadir grandes funcionalidades.

## Estructura

- `sami_local/.gitignore`
- `sami_local/requirements.txt`
- `sami_local/main.py`
- `sami_local/src/`
- `sami_local/data/`
- `sami_local/logs/`

## Evidencia

- Estructura local reproducible.
- Dependencias declaradas.
- Carpeta `venv/` excluida.
- Logs excluidos.
- Traceback provocado y explicado.
- Primer uso de asistente IA documentado y validado.
