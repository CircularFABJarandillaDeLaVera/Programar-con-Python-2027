# Mapa mental - Bloque 6

## Centro

Del notebook al entorno de desarrollo profesional.

## Progresion

NOTEBOOK -> SCRIPT -> VS CODE -> PROYECTO -> VENV -> DEPENDENCIAS -> GIT -> GITHUB -> DEBUGGER -> ASISTENTE IA

## Ramas

- Script `.py`: salida explicita con `print`.
- VS Code: editor, explorador, terminal integrada e interprete.
- Proyecto: `src`, `data`, `logs`, configuracion y rutas relativas.
- venv: entorno aislado y `requirements.txt`.
- Git: estado, preparacion y version local.
- GitHub: remoto y sincronizacion conceptual.
- Traceback: archivo, linea y tipo de error.
- Breakpoint: pausar para inspeccionar variables.
- Asistente IA: ayuda pequena siempre revisada.

## Lagunas

Instalacion local, configuracion grafica detallada, autenticacion remota y asistentes comerciales requieren documentacion oficial o preparacion previa del aula.
