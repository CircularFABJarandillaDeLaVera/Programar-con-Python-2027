# Practica 05 - Traceback, breakpoint e IA controlada

## Traceback

Provoca un error controlado:

```python
precio = float("abc")
print(precio)
```

Lee:

- archivo;
- linea;
- tipo de error;
- causa probable.

## Breakpoint

Decide donde pausarias si falla:

```python
precio_final = precio * 1.21
```

## Asistente IA

Usos permitidos:

- explicar codigo;
- proponer cambio pequeno;
- generar funcion sencilla;
- ayudar a localizar un error;
- revisar una propuesta.

## Validar

Antes de aceptar una sugerencia: leer, probar y comparar salida.
