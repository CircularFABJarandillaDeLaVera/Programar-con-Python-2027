# Practica 01 - Notebook a script

## Concepto breve

Un notebook puede mostrar la ultima expresion. Un script `.py` necesita salida explicita.

## Configurar

Crea `limpiador.py`.

## Probar

```python
resultado = "python".upper()
resultado
```

## Ejecutar

Observa que en script no se imprime nada.

## Corregir

```python
resultado = "python".upper()
print(resultado)
```

## Validar

El archivo no contiene `%pip`, `!ls` ni sintaxis de notebook.
