# Practica 02 - VS Code, interprete y terminal

## Requisito tecnico / laguna

La instalacion local de Python y VS Code no esta detallada en las fuentes. Debe comprobarse previamente en el aula.

## Configurar

Abre el proyecto en VS Code y localiza:

- explorador de archivos;
- editor;
- terminal integrada;
- interprete Python activo.

## Probar

```python
import sys
print(sys.executable)
```

## Diagnosticar

Si aparece `ModuleNotFoundError`, revisa si el interprete que ejecuta coincide con el que tiene dependencias.

## Validar

Anota ruta de interprete y carpeta raiz abierta.
