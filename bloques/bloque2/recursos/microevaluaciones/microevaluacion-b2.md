# Microevaluaciones B2

Preguntas autonomas con feedback breve.

1. Que imprime `"Pradera"[0]`?
2. Que devuelve `"Pradera"[1:4]`?
3. Que hace `palabra[::-1]`?
4. Que estructura permite cambiar `alumnos[1]`?
5. Que falta en `(5,)` para que sea tupla de un solo elemento?
6. Que vale `len(set(["Ana", "Ana", "Luis"]))`?
7. Completa: `conteo[p] = conteo.___(p, 0) + 1`.
8. Que entrega `.items()` al recorrer un diccionario?
9. Que contiene `[n for n in [1,2,3,4] if n % 2 == 0]`?
10. Que estructura eliges para contar palabras?
11. Que estructura eliges para nombres unicos?
12. En un indexador, donde guardas frecuencias?
