# Practica 02 - Listas y mutabilidad

## Objetivo

Modificar listas por indice y observar que la coleccion cambia.

## Codigo

```python
alumnos = ["Ana", "Luis", "Marta"]
alumnos[1] = "Leo"
alumnos.append("Nora")
print(alumnos)
```

## Predice

Que lista queda despues de sustituir y anadir?

## Modifica

Añade dos nombres, cambia el primero y elimina uno con `remove`.

## Mini-reto

Crea una lista de tareas. Sustituye una tarea pendiente por una tarea completada.

## Feedback

Una lista es adecuada cuando necesitas conservar orden y permitir cambios.
