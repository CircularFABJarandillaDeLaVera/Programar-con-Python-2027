# Practica 06 - Eleccion de estructuras

## Objetivo

Elegir entre string, lista, tupla, set y diccionario segun la necesidad.

## Problemas

1. Guardar una frase original.
2. Mantener una lista editable de tareas.
3. Representar un punto fijo con dos valores.
4. Eliminar nombres repetidos.
5. Contar cuantas veces aparece cada palabra.

## Predice

Antes de programar, elige una estructura para cada problema.

## Ejecuta

Escribe un ejemplo minimo para cada eleccion.

## Feedback

Justifica con una palabra clave: orden, cambio, estabilidad, unicidad o clave-valor.
