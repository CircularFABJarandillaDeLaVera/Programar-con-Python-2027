# Practica 04 - Bucles y conteos

## Objetivo

Usar `for`, `range`, `while`, `break` y `continue`.

## Ejecuta

```python
contador = 0

for numero in range(1, 31):
    if numero % 3 != 0:
        continue
    contador += 1

print(contador)
```

## Modifica

Cuenta multiplos de 5 entre 1 y 100.

## Predice

Que imprime `range(2, 11, 2)`?

## Reto

Pide numeros hasta que el usuario escriba 0. Muestra cuantos numeros se han introducido.
