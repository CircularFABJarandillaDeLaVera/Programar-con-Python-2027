# Practica 03 - Media de notas

## Objetivo

Pedir datos, convertirlos y mostrar una media con f-string.

## Ejecuta

```python
nota1 = float(input("Nota 1: "))
nota2 = float(input("Nota 2: "))
nota3 = float(input("Nota 3: "))

media = (nota1 + nota2 + nota3) / 3
print(f"Media: {media:.2f}")
```

## Modifica

Cambia el programa para calcular la media de cinco notas.

## Predice

Antes de ejecutar, calcula una prueba facil: 5, 5 y 8.
