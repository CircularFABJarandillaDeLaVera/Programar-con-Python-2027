# Practica 02 - Tramos de edad y precios

## Objetivo

Usar `input`, casting, comparaciones y condicionales.

## Ejecuta

```python
edad = int(input("Edad: "))

if edad < 12:
    precio = 5
elif edad >= 65:
    precio = 4
else:
    precio = 8

print(f"Precio: {precio} euros")
```

## Modifica

Añade un tramo adolescente de 12 a 17 años con precio 6.

## Predice

Prueba mentalmente con 10, 16, 30 y 70.

## Reto

Crea un programa que clasifique una nota en insuficiente, aprobado o notable.
