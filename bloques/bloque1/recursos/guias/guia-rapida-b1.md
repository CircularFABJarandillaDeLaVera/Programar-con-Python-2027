# Guia rapida - Bloque 1

1. Abre un notebook o Google Colab.
2. Escribe una celda corta.
3. Predice la salida.
4. Ejecuta.
5. Lee el error o resultado.
6. Modifica una sola cosa.
7. Ejecuta otra vez.
8. Explica que ha cambiado.
9. Valida con un caso facil.

Flujo con IA: problema -> plan -> codigo/IA -> ejecutar -> entender -> depurar -> modificar -> validar.
