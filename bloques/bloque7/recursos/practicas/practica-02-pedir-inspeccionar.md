# Practica 02 - Pedir e inspeccionar

## Mala peticion

```text
Haz SAMI Final completo y mejoralo todo.
```

## Buena peticion

```text
Modifica solo la funcion filtrar_stock_bajo para devolver productos con stock menor que el umbral. No cambies otras funciones.
```

## Inspeccionar

Busca:

- dependencias nuevas;
- rutas absolutas;
- APIs inventadas;
- cambios fuera del archivo pedido;
- comportamiento no probado.

## Decision

Marca cada propuesta como aceptar, modificar o rechazar.
