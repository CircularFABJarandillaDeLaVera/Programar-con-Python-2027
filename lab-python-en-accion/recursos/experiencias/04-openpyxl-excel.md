# OpenPyXL - Python trabaja con Excel

## VER

Vas a crear un archivo Excel con ventas, importes, formulas y formato basico.

Resultado: `ventas_lab.xlsx`.

## PROBAR

Instalacion:

```bash
pip install openpyxl
```

Ejecuta:

```bash
python ../scripts/crear_excel.py
```

## MODIFICAR

Anade una nueva fila de producto y ajusta la formula total.

## MINI-RETO

Pinta de otro color las filas con muchas unidades.

## Plan B

Si Excel no deja guardar, cierra el archivo y vuelve a ejecutar. Si no tienes Excel, abre el `.xlsx` con LibreOffice, Google Sheets o conserva el archivo generado.

## Que no entra

No se trabajan macros, tablas dinamicas, graficos complejos ni automatizacion de la aplicacion Excel.
