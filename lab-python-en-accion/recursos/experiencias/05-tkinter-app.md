# Tkinter - Convierte tu codigo en una app

## VER

Vas a crear una pequena ventana con campo de texto, boton y resultado.

Resultado: una app local que saluda al usuario.

## PROBAR

Tkinter suele venir con Python.

Ejecuta:

```bash
python ../scripts/mi_app_tkinter.py
```

## MODIFICAR

Cambia el texto del boton y el mensaje final.

## MINI-RETO

Anade un segundo campo para la edad y muestra una frase con nombre y edad.

## Plan B

Si Tcl/Tk no esta disponible o el equipo no puede abrir ventanas, adapta la funcion a consola con `input()` y `print()`.

## Que no entra

No se hacen apps multipantalla, bases de datos, empaquetado `.exe` ni interfaces avanzadas.
