# Pillow - Modifica una foto con Python

## VER

Vas a abrir una imagen neutra de prueba, transformarla y guardar una nueva imagen.

Resultado: `foto_editada.jpg`.

## PROBAR

Instalacion:

```bash
pip install Pillow
```

Ejecuta:

```bash
python ../scripts/editar_foto.py
```

El script usa `../assets/foto_original.ppm`, una imagen neutra creada para esta practica.

## MODIFICAR

Cambia el tamano final, el angulo de rotacion o el recorte.

## MINI-RETO

Genera dos salidas: una en escala de grises y otra recortada.

## Plan B

Si no encuentra la imagen, comprueba que existe `lab-python-en-accion/recursos/assets/foto_original.ppm` y ejecuta el script desde su carpeta o con la ruta indicada.

## Que no entra

No se usan logos corporativos como imagen de recorte, ni IA generativa, ni edicion profesional.
