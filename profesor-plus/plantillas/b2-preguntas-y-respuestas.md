# B2 - Preguntas y respuestas esperadas

## Preguntas

- Que imprime `"Pradera"[1:4]`?
- Que cambia si uso `[::-1]`?
- Que estructura permite cambiar elementos por indice?
- Que estructura elimina duplicados?
- Por que `.get(palabra, 0)` evita un fallo?
- Que estructura usar para contar palabras?
- Que evidencia demuestra que el indexador funciona?

## Respuestas esperadas

- El alumno identifica inicio, final y paso.
- Distingue string inmutable de lista mutable.
- Elige set para unicidad.
- Elige diccionario para relacion clave-valor.
- Justifica la estructura por la necesidad del problema.
