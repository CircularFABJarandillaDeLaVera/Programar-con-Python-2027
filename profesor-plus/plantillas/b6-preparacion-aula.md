# B6 Preparacion de aula

## Comprobacion previa

- Python disponible en los equipos.
- VS Code disponible.
- Extension Python/Jupyter si el aula la usa.
- Terminal integrada funcional.
- Permisos para crear carpetas.
- Acceso a Internet solo si la practica lo requiere.

## Requisito tecnico / laguna

La instalacion fisica de Python, VS Code, PATH y extensiones no esta detallada en las fuentes. Prepararla antes de clase o usar equipos ya configurados.

## Problemas habituales

- Python no aparece en terminal.
- VS Code usa otro interprete.
- `pip` instala fuera del entorno.
- No aparece `(venv)`.
- Rutas absolutas copiadas de otro equipo.

## Plan rapido

Si falla el entorno: trabajar con arbol de carpetas, lectura de tracebacks simulados y protocolo de validacion.
