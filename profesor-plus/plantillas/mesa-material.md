# Mesa del instructor

## Preparacion

- Notebook o Google Colab abierto.
- Copia local opcional de ejemplos `.py`.
- Lista de microevaluaciones.
- Practicas B1 impresas o accesibles.
- Plan B sin Internet.

## Antes de empezar

- Comprobar que se puede ejecutar una celda.
- Tener preparado un error de casting con `input()`.
- Tener un ejemplo de `if edad = 18:` para corregir en grupo.
- Tener una solucion generada por IA para analizarla, no para copiarla.
