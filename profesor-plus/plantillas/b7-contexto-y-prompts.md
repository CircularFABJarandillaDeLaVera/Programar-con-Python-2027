# B7 Contexto y prompts

## Mala peticion

```text
Haz mi proyecto completo y mejoralo todo.
```

## Buena peticion

```text
Archivo: src/analizador.py
Funcion: filtrar_stock_bajo
Objetivo: devolver filas con stock menor que el umbral
Restriccion: no anadir dependencias ni cambiar otros archivos
Validacion: con stock [0, 3, 8] y umbral 4 devuelve 0 y 3
```

## Preguntas para clase

- Que contexto falta?
- Que limite protege el proyecto?
- Como sabremos que funciona?
- Que harias si aparece una dependencia nueva?
