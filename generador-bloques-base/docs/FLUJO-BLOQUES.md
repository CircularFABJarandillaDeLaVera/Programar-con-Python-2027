# Flujo dinamico para nuevos bloques

1. Extraer y validar conocimiento desde las fuentes del curso.
2. Crear `config-bloqueX.json`.
3. Ejecutar:
   `python generador-bloques-base/scripts/crear_bloque.py config-bloqueX.json .`
4. Sustituir contenido provisional por los JSON validados.
5. Generar recursos, mapa y artefactos derivados.
6. Integrar con Codex.
7. Auditar contenido, rutas y accesibilidad antes de publicar.
